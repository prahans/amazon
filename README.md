# 🛒 Amazon UI Clone

An Amazon-inspired homepage UI clone built using **HTML** and **CSS**. This project focuses on recreating the visual appearance of Amazon's landing page, including the navigation bar, hero section, product cards, and footer.

> **Note:** This is a frontend UI project created for learning purposes. It does not include responsive design, JavaScript functionality, authentication, shopping cart features, or backend integration.

---

## ✨ Features

- 🧭 Amazon-inspired navigation bar
- 🏠 Hero (landing) section
- 🛍 Product category cards
- 📦 Product showcase sections
- 🦶 Amazon-style footer
- 🎨 Clean UI layout built with HTML and CSS

---

## 🛠 Technologies Used

- HTML5
- CSS3
